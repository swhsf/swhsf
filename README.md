# MemoWord_MiniProgram

#### 介绍
MemoWord 英语单词记忆小程序 | 高效背单词工具

一款轻量、无广告的微信背单词小程序，基于艾宾浩斯遗忘曲线实现智能复习，支持单词学习、生词收藏、进度统计、每日打卡等功能，适合学生、职场人士利用碎片时间提升英语词汇量。

#### 软件架构
微信小程序原生架构
采用 WXML + WXSS + JavaScript + JSON 开发
使用本地缓存实现数据持久化存储
模块化组件设计，易于维护与扩展

#### 安装教程

1.  下载并安装微信开发者工具
2.  克隆本项目到本地目录
3.  打开微信开发者工具，导入项目
4.  配置小程序 AppID（测试可使用测试号）
5.  点击编译，直接运行预览

#### 使用说明

1.  进入小程序，选择词库开始单词学习
2.  查看单词释义、例句、发音，完成记忆
3.  收藏陌生单词至生词本，便于专项复习
4.  查看学习统计，追踪每日记忆进度
5.  系统根据遗忘曲线自动推送复习任务
